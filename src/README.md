# 🧠 EmpathAI — Emotionally Intelligent User Experience

> Built for AX Hackathon | Problem Statement 05

## 🌟 What is EmpathAI?

EmpathAI is a multimodal, context-aware AI platform that delivers emotionally intelligent, personalised user experiences. It detects the user's emotional state and adapts the entire interface — colors, tone, and content — in real time.

## 🚀 Live Demo
👉 [Click here to try EmpathAI](https://emphathai-app.vercel.app)

## ✨ Features

| Feature | Description |
|---|---|
| 🎭 Mood Detection | 5 mood states detected via user input |
| 🎨 Adaptive UI | Entire app theme changes based on mood |
| 🤖 Empathetic AI Chat | Powered by Google Gemini 2.0 Flash |
| 🎤 Voice Input | Speak instead of type — multimodal input |
| 🧘 Breathing Exercise | Auto-triggered for Stressed/Sad users |
| 💙 Crisis Support | Helpline shown for distressed users |
| 📊 Mood Dashboard | Bar chart tracking emotional journey |
| ⭐ Feedback Rating | Rate every AI response |
| ♿ Accessibility Modes | Large text, high contrast, calm mode |
| 💬 Daily Affirmations | Mood-based motivational messages |

## 🔒 Privacy

- All emotion inference happens client-side
- No biometric data stored or transmitted
- API key secured via environment variables

## 🚀 Run Locally

```bash
git clone https://github.com/Ayisha-2803/emphathai-app.git
cd emphathai-app
npm install
echo REACT_APP_GEMINI_KEY=your_key_here > .env
npm start
```
